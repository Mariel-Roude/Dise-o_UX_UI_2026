Caso de Estudio

Caso de Estudio: Cubri Seguros

El Problema

El desafío consistía en construir el front-end de un sistema de contratación de seguros de celulares online. El proceso debía ser claro, evitar errores del usuario y calcular dinámicamente los precios del seguro según las características del equipo.

La Solución

Desarrollé un flujo de 7 pantallas utilizando JavaScript Vanilla para manejar el estado del formulario (guardando los datos del usuario a medida que avanzaba) y Tailwind CSS para la interfaz responsiva.

  • Validación en tiempo real: El usuario no podía avanzar si el DNI o el email no eran válidos.
  • Cálculo dinámico: Si el celular valía $600.000 y tenía 1 año de antigüedad, el plan Plus se calculaba exactamente en $3.300.

Resultados y Aprendizajes

Logré un flujo funcional sin recargar la página, demostrando que se puede crear una experiencia de usuario fluida con tecnologías base. Aprendí la importancia de la lógica de estado en JavaScript y cómo un diseño claro reduce la frustración del usuario en procesos de pago.
