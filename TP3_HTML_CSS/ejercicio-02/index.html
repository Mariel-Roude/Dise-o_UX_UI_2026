Cómo preparar mate

Pasos

  1. Llenar el mate hasta tres cuartos con yerba.
  2. Tapar la boca del mate y sacudirlo para que el polvillo quede arriba.
  3. Inclinar el mate e inyectar un poco de agua tibia en el hueco.
  4. Colocar la bombilla en el hueco sin moverla después.
  5. Cargar agua a unos 75 °C (sin hervir) y disfrutar.
